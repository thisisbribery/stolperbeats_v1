Stolperbeats shuffle, decoded

Pick a Timing, turn the Shuffle control, and watch a bar of drums get pushed off the grid. All four Timings and all seven Shuffle settings come from the step tables in firmware 163, and every hit is placed the same way the module places it. Feel is Tight, so every track moves together. Stolperbeats only sends triggers, so the kits are synthesised stand-ins for the drum machines you would patch to its six trigger outs.

Half a bar up close: the firmware's 8-step cycle

✓ Read from the firmware code

  • Ticks per beat for each Shuffle setting: 0x08029948
  • Step lengths: Trip 0x08029788, Shake 0x080297F8, Push 0x08029868, Clave 0x080298D8
  • SHUFFLE is clamped to 0 to 6, and the row is shuffle + 7 × timing (0x080097E8)
  • At boot, step lengths become running totals (0x0800D430)
  • Tick length = 60 × 48014 ÷ (bpm × ticks per beat) timer counts, which is exactly 1/N of a beat (0x08003BB8)
  • A step fires when the tick counter equals its running total. The first 8 totals replay every half bar (0x08010E58)

≈ Matched, not traced in code

  • Which table belongs to which button. The four tables sit in button order and match the manual's descriptions: Trip's tuplet shapes, Push making time for the downbeat, and Clave's 3:3:2 holding still.
  • Tight feel applying the tables unchanged. The Feel code hasn't been traced.
  • Nothing here has been measured on the hardware yet.
  • The 808, 909 and 606 kits are synthesised approximations, not samples.
